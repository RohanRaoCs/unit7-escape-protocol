Learning lab

A second agent learns the escape by trial and error using tabular Q-learning, on a smaller facility with two keycards and no lock. It starts knowing nothing and gradually learns which move is best in each situation. The lab then asks: what happens to a learned behaviour when the world changes? The training runs in Python (escape_room/qlearn.py) inside your browser.

Starting Python…

1Train. Press "Train 500 episodes" two or three times. The blue curve should fall until it meets the purple A* optimum.
2Test. Press "Play greedy policy" to watch the learned behaviour, then "Show A* route" to compare it with search.
3Break it. Press "Collapse the learned route". The policy walks into the new wall, while A* simply reroutes. Train again to watch it recover.

What these settings do

After each move the agent updates its estimate Q(state, move) toward reward + γ × best estimate from the next state. α sets how big that step is. Early on it explores randomly (ε = 1); ε shrinks every episode, so it increasingly follows what it has learned. Changing a setting starts a fresh lab.

Rewards: −1 per step, −5 for walking into a wall, +30 for each new keycard, +100 for exiting with both.

How to read the map

Each arrow is the move the agent currently thinks is best from that cell. Darker blue means a higher learned value: the agent expects to reach the exit sooner from there. Cells without arrows have never been visited. Because the right move depends on which keycards are held, use the selector to switch between "no keycards", "one keycard" and so on.

How to read the learning curve

Grey: steps taken in each episode. Blue: the 50-episode average, which should fall as the agent learns. Green: the share of recent episodes that reached the exit (scaled to the chart). Purple: the shortest possible escape, found by A*. An orange line marks each collapse you trigger.
