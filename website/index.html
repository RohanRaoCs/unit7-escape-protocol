An android has to escape a facility that keeps changing around it.

UNIT-7 must collect three keycards, crack a vault lock and reach the exit while a drone hunts it, laser gates switch on and off, ceilings collapse onto its route and the lock rewires itself. It gets out by combining six AI techniques: search, constraint satisfaction, a behaviour tree, fuzzy logic, a state machine and reinforcement learning. Everything is written in Python and runs right here in your browser.

Six techniques, each with one job

None of them is decoration: switch any one off in the simulator and the agent behaves measurably worse.

A* search

Finds the cheapest route, steers around danger, and times its way through laser gates by planning in time as well as space.

Read more

Constraint satisfaction

Generates a fair vault-lock puzzle and solves it with forward checking, MRV and AC-3, then re-solves it when the clues change.

Read more

Behaviour tree

Decides what to do each tick: survive first, then escape, crack the lock, or collect keycards.

Read more

Fuzzy logic

Turns "how close, how alert, how damaged" into one threat score that shapes routes and triggers evasion.

Read more

Finite state machine

Runs the security drone: patrol, investigate, chase and cool down.

Read more

Q-learning

A second agent learns the escape by trial and error, which shows why planning copes better when the map changes.

Read more
