Testing guide

Everything needed to verify the project: an automated test suite that runs right here in the browser, a checklist that walks through each requirement of the brief in the simulator, and the commands for running the tests and benchmark from a terminal.

1. Run the automated tests

19 tests check that the algorithms are correct, not just that they run: A* is optimal, space-time paths never cross an active laser, every lock has exactly one solution, the fuzzy rules behave sensibly, and the agent clearly beats a fixed plan. This button runs the Python test code (escape_room/checks.py) in your browser, which takes one to two minutes. The same tests run from a terminal with python -m unittest -v in under a minute.

3. Measure performance

The brief asks for evaluation using completion time, path cost, states explored and success rate. Open the Benchmark page and press Run experiment with the defaults (10 Dynamic facilities). Expect the full UNIT-7 agent to escape nearly every time and the fixed script only about one time in five. The page also shows reference results from 100 facilities for comparison.

4. Run it from a terminal

You need Python 3.9 or later. Only the standard library is used, so there is nothing to install.

# get the code
git clone https://github.com/RohanRaoCs/unit7-escape-protocol.git
cd unit7-escape-protocol

# desktop demo window (Tkinter)
python main.py

# the 19 correctness tests (the same ones as above)
python -m unittest -v

# full evaluation on 100 facilities per design, about 3 minutes; writes results/summary.md and CSVs
python evaluate.py

# this website, locally, at http://localhost:8000
python -m http.server

5. Deploy your own copy

The site is static: HTML pages, a little JavaScript for drawing, and the Python package, which Pyodide runs in the browser. There is no build step, so it can be hosted anywhere.

Vercel

Fork the repository on GitHub, then in Vercel choose Add New → Project, import the fork and press Deploy. No settings need changing; vercel.json is already included.

GitHub Pages

In the repository, go to Settings → Pages, choose "Deploy from a branch", select main and / (root), and save. The site appears at <user>.github.io/unit7-escape-protocol.
