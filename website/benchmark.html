Benchmark

Runs many complete missions, without animation, on the same seeded facilities for each agent design, and compares them. Every facility is generated from its seed, so anyone running the same settings gets the same numbers. The runs use the same Python code as python evaluate.py, running in your browser; nothing is sent anywhere.

Starting Python…

1Pick designs. Keep all seven ticked to see the full comparison, including the fixed-script baseline.
2Choose a facility. "Dynamic" is the main test. 10 facilities take about a minute in the browser; the report uses 100 (run python evaluate.py for those, about 3 minutes).
3Run and read. Green values are the best in each column. Download the CSV to check any run individually.

Mission experiment

Each ticked design runs a full mission on every facility.

What the designs differ in
  • UNIT-7 full: every technique on. This is the agent in the simulator.
  • Snapshot planning: ignores the laser gate timetable.
  • Crisp avoidance: replaces fuzzy logic with a fixed rule.
  • Dijkstra / Greedy / BFS: swap A* for another search algorithm.
  • Fixed script: plans once at the start and never reacts. This is the "fixed sequence of actions" the brief warns against.

Component experiments

Test one technique in isolation, on identical problems.

What each measure means

  • Success: share of missions that escaped within 900 ticks with the hull intact.
  • Ticks: completion time. One tick is one move or one wait. Averaged over successful runs.
  • Path cost: the sum of the step costs actually paid (1 per cell, 6 on coolant).
  • States explored: search nodes expanded by every plan in the mission. This measures computational effort.
  • Replans: how many times a plan was thrown away because the world changed.
  • Drone hits / laser zaps: damage events. Integrity: hull remaining at the end.
